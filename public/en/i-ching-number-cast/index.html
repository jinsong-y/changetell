CHANGE_TELL guide

I Ching Number Cast

Number Cast in CHANGE_TELL lets a user enter numbers for a Mei Hua Yi Shu reading while keeping the hexagram calculation transparent and repeatable.

How the numbers are used

The app accepts numbers from 1 to 999. The upper number maps to the upper trigram, the lower number maps to the lower trigram, and an optional third number maps to the moving line. If the moving number is not supplied, the app still applies a deterministic rule rather than asking AI to decide.

Why deterministic casting matters

A deterministic number cast makes the boundary clear. The program performs the I Ching and Mei Hua Yi Shu calculation. AI receives the calculated payload and writes interpretation, advice, and plain-language explanation from those fixed values.

Best use cases

Number Cast is useful when a user has a spontaneous number, a set of meaningful numbers, or wants to avoid repeating a time-based question in the same two-hour period.
